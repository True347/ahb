}

Note: `Phase 0 Cargo.toml does NOT depend on reqwest`. The `ProviderError::Network` variant therefore wraps a stub `NetworkErr(String)` newtype defined in `model.rs` — NOT `reqwest::Error`. CONTEXT D-12 says "reqwest::Error wrapper" in shorthand, but the actual type is `pub struct NetworkErr(pub String)` in Phase 0 to avoid pulling reqwest as a Phase 0 dep. Phase 3 will widen it to wrap `reqwest::Error` proper.

W-2 design note: `ProviderState.source` is `Cow<'static, str>` rather than `&'static str`. Rationale:
- `&'static str` does not freely deserialize via `serde_json::from_str` — borrowed `&str` deserialization requires `'de: 'static` which is impossible from an owned `String` buffer.
- `Cow<'static, str>` accepts `Cow::Borrowed("mock")` from adapters (zero-cost static label) AND deserializes round-trip into `Cow::Owned(String)` from JSON.
- This preserves adapter ergonomics while making the field serde-symmetric.
- Plan 03's MockProvider sets `source: Cow::Borrowed("mock")`; the model.rs round-trip test asserts that after `to_string` → `from_str` the field becomes `Cow::Owned("mock".to_string())` and still compares equal via `==`.
