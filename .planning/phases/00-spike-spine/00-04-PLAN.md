  <how-to-verify>
    The HUMAN (Chasel) must run these three commands on their machine and capture verbatim output (copy-paste into a scratch file or directly into the memo draft). Sanitize any session IDs / personal usage numbers before committing.

    **Prerequisite:** Confirm `gemini` CLI is installed: `gemini --version`. If absent, install per https://github.com/google-gemini/gemini-cli or mark the spike as "tool unavailable → no-go" per D-22 fallback (acceptable outcome).

    **Probe 1 — Canonical non-interactive slash command** (RESEARCH Pitfall 1 step 1):
    ```
    gemini -p "/stats" 2>&1
    ```
    Capture: verbatim stdout+stderr, exit code (`echo $?` after). Likely behavior per gemini-cli PR #8305: either fails with "built-in commands not supported" OR treats `/stats` as a literal LLM prompt and returns chat-response nonsense. Either way, record exactly what happens.

    **Probe 2 — Stdin pipe variant** (Pitfall 1 step 2):
    ```
    printf '/stats\n' | gemini 2>&1
    ```
    Capture: verbatim, exit code. May hang per issue #16567 — if it hangs >30s, kill with Ctrl-C, record "HANG: killed after 30s".

    **Probe 3 — Most-promising path: harvest `stats` object from JSON output** (Pitfall 1 step 3 + RESEARCH Assumption A1):
    ```
    gemini -p "ok" --output-format json 2>&1
    ```
    Capture: verbatim JSON output, exit code. Per RESEARCH lines 347-350 + gemini-cli PR #15021 + headless.md, `--output-format json` is documented to include a `stats` object with token counts. The hypothesis: even though `/stats` itself may not work non-interactively, AHB can invoke ANY trivial prompt (e.g., `gemini -p "ok"`) just to harvest the `stats` block from the response envelope.

    **What to look for in Probe 3 JSON:**
    - Is there a top-level `stats` key?
    - Does it contain a per-model token count (`totalTokens`, `inputTokens`, `outputTokens`, `cachedTokens`)?
    - Does it contain ANY field encoding reset-window or session-quota boundary (e.g., `sessionDuration`, `quotaRemaining`, `windowStart`)?

    **Anonymize before recording:** strip any project IDs, account emails, session UUIDs. Quota numbers (e.g., "1.2M tokens used today") are personal-looking enough to anonymize too — replace with `<ANONYMIZED-USAGE>`.

    **Verify rendering of Phase 0 binary (parallel task per D-26):** While at the terminal, also run:
    ```

    /home/chasel/REPO/AIHPBar/target/release/ahb > /tmp/ahb-out.txt && xxd /tmp/ahb-out.txt | head -3
    ```
    Capture the xxd output too — Plan 05 will use it for charset verification, but having it at hand during memo writing is convenient.
