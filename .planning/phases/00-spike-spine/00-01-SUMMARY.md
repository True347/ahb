## Decisions Made

- **D-04 (clippy disallowed-types form):** The plan's action said "A `disallowed-types` entry blocking direct `crossterm::*` use". Clippy's `disallowed_types` lint only accepts fully-qualified type paths, not glob patterns. I added concrete entries for `crossterm::event::Event` and `crossterm::style::Color` (the two surfaces most likely to be tempting to import directly). Adding the glob would have caused clippy to silently no-op the rule, which is worse than the current explicit list. The deny-list grows in Plan 03+ as new crossterm surfaces become attractive footguns; this is a Phase 1 follow-up if rendering ever requires more crossterm types via owo-colors.
- **W-1 rationale comment placement:** Comment lives on the line directly above the `tokio = ...` line so `grep -B1 -E '^tokio = ' Cargo.toml | grep -q 'Phase 0 dep minimalism'` finds it — exactly the verification command from the acceptance criteria.
- **No other discretionary calls** — Task 2's stub character of `src/main.rs` (empty `fn main()`, no `println!`) followed the plan verbatim. Task 3 used the verbatim YAML template from RESEARCH.md § "3-OS matrix" (lines 670-699).
