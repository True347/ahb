<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fanout results → cache write | ProviderState from adapter; fetched_at must come from FetchCtx::now not wall clock |
| cache read → RowOutcome::Stale | Stale state is user-visible; must not leak secrets or stale age beyond what state already contains |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Information Disclosure | moka cache contents | accept | Cache is pure in-memory (D-66), never serialized to disk or --json output (D-68); no secret values are stored in ProviderState (ProviderState is a display DTO) |
| T-03-02-02 | Denial of Service | refresh_interval = 1s (below clamp) | mitigate | Clamp to ≥5s in Engine::new with tracing::warn!; D-72 binding |
| T-03-02-03 | Tampering | is_transient widens to include Unavailable | mitigate | is_transient is a private(crate) helper with 6 explicit unit tests; Unavailable returns false explicitly per Q2; widening requires test changes |
| T-03-02-04 | Elevation of Privilege | unreachable!() in CLI RowOutcome::Stale arm | accept | Stale requires TUI-long-lived cache which CLI never builds; the unreachable!() is a correctness assertion, not a user-triggered path |
