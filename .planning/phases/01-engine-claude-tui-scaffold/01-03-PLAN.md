## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| terminal escape sequences → user shell | A malformed render or unhandled panic could leak escape sequences that scramble the user's terminal (TUI-04 is the binding mitigation); `ratatui::run` panic hook composes on top of Phase 0's hook to restore mainscreen + cursor + cooked mode before stderr writes |
| stdin keystrokes → TUI event loop | `crossterm::event::EventStream` parses incoming bytes; ratatui's parser is the trust boundary — we never echo user-typed bytes back as renderable content |
| Adapter panic during refresh tick → process | Engine fan-out already converts `JoinError::is_panic()` to `ProviderError::Internal` (Plan 01); the TUI consumes the resulting `RowState::Err` cleanly; the process panic path (panic on the render thread or in `ratatui::run`'s machinery) is what TUI-04 covers |
| Config-driven mock enable → operator control surface | `[providers.mock] enabled = true` + `AHB_DEBUG_PANIC=adapter:mock` is the documented panic-injection path — accepted attack surface for operator-controlled testing |
