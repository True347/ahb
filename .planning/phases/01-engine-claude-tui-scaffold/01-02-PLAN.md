|----------|-------------|
| keyring backend → process | OS-native store returns secret bytes into our process memory; we wrap in `Secret<T>` immediately so the unwrapped form has bounded lifetime + zeroize-on-drop |
| stdout / stderr / logs → operator | Any path that touches a `Secret<T>` value via Display/Debug/Serialize must be redacted; CI grep test holds the line |
